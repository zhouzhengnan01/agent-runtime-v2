# gpu-training-orchestrator

This is now a pure YOLO training skill.

It receives a prepared YOLO `dataset.yaml` from `data-auto-annotation` and only runs:

- YOLO training
- test split evaluation
- training artifact collection
- training logs

## Responsibility Boundary

This skill must not perform dataset processing:

- no dataset inspection
- no SAM3 auto annotation
- no synthetic image planning
- no image generation
- no COCO merge
- no train/val/test split
- no COCO to YOLO conversion
- no image copying for dataset preparation

All of those operations belong to `data-auto-annotation`.

## Input JSON

```json
{
  "runtime": {
    "conda_env_name": "yolo_jetson",
    "enforce_conda_env": true
  },
  "dataset": {
    "data_yaml": "D:/work/prepared_data/dataset.yaml"
  },
  "training": {
    "task": "detect",
    "model": "yolo11n.pt",
    "epochs": 50,
    "imgsz": 640,
    "batch": 16,
    "device": "0",
    "workers": 4,
    "patience": 8
  },
  "output": {
    "project_dir": "D:/runs/yolo",
    "run_name": "exp"
  }
}
```

## CLI

```powershell
python scripts/run_prepared_yolo_training.py --input D:/work/training_input.json
```

## Output

The script writes standard Ultralytics outputs:

- `train/weights/best.pt`
- `train/weights/last.pt`
- `train/results.csv`
- `train/args.yaml`
- plots generated by Ultralytics
- `test_eval`
- `run_summary.json`
