# 杂物检测

发现区域内乱堆乱放杂物

## 目标

基于商场后场过道监控画面，实时判断是否存在纸箱、袋子、货物、工具、垃圾袋、塑料筐、托盘等杂物堆积在过道、墙边、门口、转角、消防设备旁等非存储区域，排除固定设施（门、灯、消防箱、指示牌、固定垃圾桶）的误判。

## 输入
监控画面：单张或连续视频帧中的商场后场过道图片，需能观察过道通行区域、墙边、门口、转角及消防设备周围。

## 判定标准
有杂物堆积：过道、墙边、门口、转角、消防设备旁出现明显堆放的纸箱/袋子/货物/工具/垃圾袋/塑料筐/托盘等；杂物散落影响通行或堵塞通道；杂物高度或范围明显占道。
无法判断：画面过暗/过曝、严重遮挡、杂物特征模糊或区域不可见。

## 约束
不处理以下情况：
固定设施：门、照明灯、消防箱、疏散指示牌、固定式垃圾桶、墙体结构、管道等。
后厨人员正常推车：人员正在移动或操作中的推车（如餐车、转运车、清洁车等），不属于静止堆放的杂物。
