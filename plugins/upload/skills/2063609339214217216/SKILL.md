# 明火 / 火焰识别

明火 / 火焰识别

## 目标

基于商场后场过道监控画面，实时判断是否存在明火、火苗、火星、火光或伴随火焰的烟雾等明显燃烧现象，排除红色灯光、反光、装饰假火、暖气设备、烟雾机等误报源。

## 输入

单张或连续视频帧中的商场后场过道图片，需能观察区域内的光源、颜色、形态及烟雾特征。

## 判定标准
有火焰：观察到明火、火苗、火星、火光，或烟雾与火焰同时出现。
无火焰：未发现任何燃烧现象，或仅存在红色灯光、反光、橙色标识、装饰假火、暖气设备、正常照明、消防演习烟雾机等。

无法判断：画面过暗/过曝、模糊、视角遮挡或火焰特征不清晰，无法确认是否存在燃烧。
## 约束
不处理以下情况：
红色灯光、反光、橙色广告牌/标识（易误判为火焰）。
