# 摔倒监测

识别人员意外摔倒、倒地行为

## 目标

基于商场安全监控画面，实时识别人员摔倒、躺卧、蹲伏、爬行等异常低姿态行为，排除正常坐姿（椅子、长椅、沙发等固定座椅）及等候休息场景，及时发现潜在安全风险，需要判断cv上报的结果是否正确。

## 输入

监控画面：连续视频帧或周期性图像序列，需覆盖人员全身姿态，能区分站立、行走、倒地、蹲伏等动作

## 判定标准
摔倒：人体由站立或行走姿态突然转变为倒地姿态。
倒地：人持续低姿态在地面上
以上任一特征满足即判定为异常状态。

## 约束
不处理以下情况：
人员坐在固定座椅上（椅子、长椅、沙发、轮椅等）的正常坐姿。
画面中只有局部肢体（如仅腿部）无法确认全身姿态的情况。
