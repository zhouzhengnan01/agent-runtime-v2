JetLinks Agent Runtime 接口文档

本页描述当前服务的运行接口、ACP WebSocket 对接方式、模型托管语义、workflow/skill/runtimeOptions 的约定。默认通用智能体走 agent loop；workflow 只有在请求显式传入时才会执行。

服务地址

http://127.0.0.1:8010。生产环境以部署网关地址为准。

核心入口

浏览器或第三方系统优先接入 /api/acp/ws；简单调试可使用 /api/agents/{agent}/runs。

鉴权

场景规则传参方式
开发模式RUNTIME_AUTH_MODE 未设置为 production 时，运行类接口默认不强制 token。无需传 token。
生产运行接口RUNTIME_AUTH_MODE=production 时，HTTP 运行接口和 ACP WebSocket 需要 RUNTIME_API_TOKEN。Authorization: Bearer <token> 或 ?token=<token>。
管理写接口只要配置了 RUNTIME_API_TOKEN，插件上传、配置保存、手动 cron 等管理写接口都要求 token。Authorization: Bearer <token>。

ACP WebSocket 对接

WS

/api/acp/ws

JSON-RPC 2.0 over WebSocket，服务端接受子协议 acp.v1 
const ws = new WebSocket('ws://127.0.0.1:8010/api/acp/ws', 'acp.v1');

ws.onmessage = (event) => {
  const packet = JSON.parse(event.data);
  if (packet.method === 'session/update') {
    console.log('runtime event', packet.params.update);
    return;
  }
  console.log('rpc result', packet);
};

字段类型说明

prompt 里可传的块

块类型字段说明
texttext纯文本内容。
imagedata / mimeType / uri图片，data 为 base64，uri 可为原始文件路径。
audiodata / mimeType / uri音频输入。

推荐调用顺序

  1. 连接 /api/acp/ws，生产模式下通过 query token 或 header 传鉴权。
  2. 发送 initialize，读取能力信息和 _meta.jetlinks.modelManagement。
  3. 发送 session/new 创建会话。产品入口推荐传 appTemplateName，由服务端从 config/apps/*.json 带出默认 agent、workflow、skill 和示例配置。
  4. 需要切换模型时发送 session/set_model，只传后端模型管理里的 modelId。
  5. 发送 session/prompt，持续接收 session/update，最后收到同 id 的 JSON-RPC result。
  6. 会话结束后发送 session/close；需要中断时发送 session/cancel。

应用模板与 runtimeOptions 优先级

应用模板是推荐的产品入口。模板 JSON 保存在 config/apps/*.json，例如 config/apps/iot-architecture-diagram.json、config/apps/project-report-ppt.json、config/apps/technical-doc-writer.json。也可以通过 GET /api/apps/templates 列出模板，或用 GET /api/apps/templates/{template_name} 查看单个模板完整 JSON。

来源作用优先级
config/apps/<name>.json应用初始配置，声明 agent_name、workflow、selected_skills、selected_mcp_tools、runtime_options、prompt_examples。基础默认值
session/new.runtimeOptions创建会话时覆盖模板默认值，并作为该 ACP session 的默认运行参数保存。高于应用模板
session/prompt.runtimeOptions只覆盖当前这一轮 prompt，适合临时切换 skill、workflow、模型或采样参数。最高

selectedSkills 只表示本轮允许或优先使用的 skill，不会单独触发 workflow。要走产物生成流程，需要模板或 runtimeOptions 同时设置 workflow: "artifact_workflow"；如果 workflow 为空、agent_loop 或 default，则进入通用 agent loop，skill 会作为模型可调用工具暴露。

// 1. 推荐：用应用模板创建会话，不必每轮手动传 workflow / selectedSkills
ws.send(JSON.stringify({
  jsonrpc: '2.0',
  id: 2,
  method: 'session/new',
  params: {
    sessionId: 's-iot-diagram',
    threadId: 'thread-iot-diagram',
    appTemplateName: 'iot-architecture-diagram'
  }
}));

// iot-architecture-diagram 来自 config/apps/iot-architecture-diagram.json，大致等价于：
// {
//   "agent_name": "default",
//   "workflow": "artifact_workflow",
//   "selected_skills": ["drawio-generation"]
// }

// 2. 后续 prompt 默认继承模板配置
ws.send(JSON.stringify({
  jsonrpc: '2.0',
  id: 3,
  method: 'session/prompt',
  params: {
    sessionId: 's-iot-diagram',
    prompt: [{ type: 'text', text: '生成一份 JetLinks IoT 平台架构图' }]
  }
}));

// 3. 如果某一轮要临时覆盖，再传 runtimeOptions
ws.send(JSON.stringify({
  jsonrpc: '2.0',
  id: 4,
  method: 'session/prompt',
  params: {
    sessionId: 's-iot-diagram',
    prompt: [{ type: 'text', text: '这一轮改成技术文档' }],
    runtimeOptions: {
      workflow: 'artifact_workflow',
      selectedSkills: ['markdown-rendering']
    }
  }
}));

ACP JSON-RPC 方法

RPC

initialize

返回协议版本、运行能力、JetLinks 扩展能力。当前会在 _meta.jetlinks 标注模型由服务端管理。

请求参数类型必填说明
protocolVersioninteger否客户端期望的协议版本，当前服务固定返回 1。
clientInfoobject否客户端名称和版本，用于日志和兼容判断。
clientInfo.namestring否客户端名称。
clientInfo.versionstring否客户端版本。
 
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {}
}
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "protocolVersion": 1,
    "agentInfo": { "name": "jetlinks-agent-runtime-v2", "version": "0.1.0" },
    "agentCapabilities": {
      "promptCapabilities": { "image": true, "audio": true, "embeddedContext": true },
      "sessionCapabilities": { "list": true, "close": true, "fork": true, "resume": true, "cancel": true },
      "transports": ["websocket"]
    },
    "_meta": {
      "jetlinks": {
        "modelManagement": "server",
        "artifactWorkspace": true
      }
    }
  }
}

返回值字段

字段类型说明
protocolVersioninteger协议版本，当前固定为 1。
agentInfoobject服务端信息。
agentCapabilitiesobject能力声明。
_meta.jetlinks.modelManagementstring模型托管模式，当前为 server。
_meta.jetlinks.runtimeOptionsstring[]当前支持的 runtimeOptions 字段名列表。
_meta.jetlinks.artifactWorkspaceboolean是否启用线程成果工作区。
RPC

session/new

创建会话。可传 agentName、threadId、appTemplateName、runtimeOptions。如果传了托管模型 ID，会解析成完整模型配置。

请求参数类型必填说明
sessionIdstring否显式指定会话 ID，不传则自动生成。
agentNamestring否要执行的 agent 名称，默认 default。
threadIdstring否线程 ID，默认自动生成。
cwdstring否会话工作目录，外部 backend 会使用它。
appTemplateNamestring否从应用模板派生会话初始配置。
runtimeOptionsobject否本次会话默认 runtimeOptions。
 
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "session/new",
  "params": {
    "agentName": "default",
    "threadId": "thread-001",
    "cwd": "/tmp",
    "runtimeOptions": {
      "modelName": "qwen-vl-30b",
      "workflow": "artifact_workflow",
      "selectedSkills": ["drawio-generation"]
    }
  }
}

返回值字段

字段类型说明
sessionIdstring新建的 ACP 会话 ID。
threadIdstring运行线程 ID。
agentNamestring最终使用的 agent 名称。
cwdstring会话工作目录。
backend.typestring后端类型。
appTemplateNamestring|null应用模板名。
runtimeOptionsobject已归一化的运行参数。
models.currentModelIdstring|null当前模型 ID。
models.currentModelNamestring|null当前真实模型名。
models.availableModelsarray可用模型列表。
RPC

session/prompt

执行一轮对话。运行中会发送多条 session/update，最终返回同 id 的 result。重复发送同一 session 的 prompt 会取消上一轮未完成任务。

请求参数类型必填说明
sessionIdstring否目标会话 ID。不传时会自动新建会话。
agentNamestring否覆盖当前会话使用的 agent。
promptstring | array是一轮输入文本或多块输入，见上面的块类型表。
runtimeOptionsobject否本轮覆盖参数，优先级高于会话默认值。
cwdstring否仅外部 backend 场景使用。
 
{
  "jsonrpc": "2.0",
  "id": 10,
  "method": "session/prompt",
  "params": {
    "sessionId": "acp-session-abc123",
    "prompt": [{ "type": "text", "text": "人员翻越围栏进入禁区" }],
    "runtimeOptions": {
      "workflow": "evidence_first_detection",
      "selectedSkills": ["behavior-detection"]
    }
  }
}

返回值字段

字段类型说明
stopReasonstring结束原因，当前通常为 end_turn，取消时为 cancelled。
threadIdstring执行线程 ID。
agentNamestring执行 agent 名称。
resultobjectAgentRunResult 的完整结果对象。
RPC

session/set_model

切换当前会话模型。推荐只传后端模型管理中的 modelId。如果 modelId 不存在，会兼容旧逻辑，把该值当作模型名。

请求参数类型必填说明
sessionIdstring是目标会话 ID。
modelIdstring是后端模型管理里的模型 ID。兼容字段 modelName / model_name。
 
{
  "jsonrpc": "2.0",
  "id": 20,
  "method": "session/set_model",
  "params": {
    "sessionId": "acp-session-abc123",
    "modelId": "qwen-vl-30b"
  }
}

返回值字段

字段类型说明
sessionIdstring会话 ID。
modelIdstring最终设置的模型 ID。
modelNamestring解析后的真实模型名。
方法作用关键参数
session/list列出当前 WebSocket 连接内的会话。无，直接返回会话列表。
session/load加载并更新已有会话的 cwd/runtimeOptions。sessionId 必填；可选 cwd、runtimeOptions。
session/fork从已有会话派生新会话。sessionId 必填；可选 newSessionId、threadId、cwd、runtimeOptions。
session/resume恢复会话；如果不存在则创建。sessionId 必填；可选 agentName、threadId、cwd、appTemplateName、runtimeOptions。
session/cancel取消当前会话正在执行的 prompt。sessionId 必填。
session/close关闭会话并清理外部 ACP backend。sessionId 必填。
list_agents列出可用 agent。无，返回当前 loader 中的 agent 列表。
jetlinks/session/delete_files删除线程工作区文件，可 dry run。sessionId 必填；可选 scopes、dryRun。

Runtime Options

在 ACP WebSocket 中，session/prompt.runtimeOptions 优先级最高，session/new.runtimeOptions 次之，appTemplateName 引用的 config/apps/*.json 作为应用默认值；服务初始化传入的模型和 skill 默认值、环境变量、agent JSON 再作为兜底。

字段说明示例
threadId线程 ID，对应 .runtime/threads/{thread_id}。thread-001
workflow显式选择 workflow。空、agent_loop、default 都表示走通用 agent loop。artifact_workflow
selectedSkills本轮允许或优先使用的 skill。不会单独触发 workflow。["markdown-rendering"]
selectedMcpTools本轮显式选择 MCP 工具。["local_read_file"]
modelName / modelIdACP 层推荐传托管模型 ID；运行时会解析为真实模型名和连接参数。qwen-vl-30b
baseUrl / apiKey调试或高级覆盖场景使用；业务接入优先只传 modelId。http://host/v1
temperature / topP采样参数。0.4
maxTokens最大输出 token。2048
requestTimeoutSeconds模型请求超时时间。120

错误码

ACP WebSocket 使用 JSON-RPC 错误码；HTTP 接口通常返回 FastAPI 的 4xx/5xx JSON 错误体。对接时优先处理下面这几类 ACP 错误。

错误码含义常见触发点
-32600Invalid Request消息不是对象，或缺少 method。
-32602Invalid params参数校验失败、会话不存在、缺少 sessionId、缺少 prompt、无效模型 ID、无效工作流名等。
-32004Not Found外部 ACP backend、线程文件或资源不存在。
-32000Server error未捕获异常、运行时内部错误、后端执行失败。

常见错误消息

消息说明
sessionId is required需要显式传入会话 ID。
prompt text or messages are requiredsession/prompt 缺少可执行输入。
Unknown ACP session: ...引用了不存在的会话。
Unknown ACP app template: ...传入的应用模板名不存在。
Unsupported ACP method: ...请求的方法未注册。
scopes must be a list of strings删除文件时 scopes 类型不正确。
Unsupported ACP file deletion scope: ...删除文件时传入了非法 scope。

ACP 事件流

执行期间服务端发送 session/update notification。原始运行事件会放在 update._meta.jetlinksRuntimeEvent 中。

{

runtime eventsessionUpdate说明
run.startedagent_thought_chunk本轮执行开始，原始事件在 _meta.jetlinksRuntimeEvent。
llm.startedagent_thought_chunk模型参数已解析，包含 model、temperature、max_tokens 等。
llm.request.startedagent_thought_chunk每轮 LLM 请求开始，包含 round、mode、message_count、tool_count、tools、tool_choice。
llm.request.completedagent_thought_chunk每轮 LLM 请求完成，包含 duration_ms、finish_reason、tool_call_count、tool_calls、usage。
agent.message.deltaagent_message_chunk流式文本片段。
agent.messageagent_message_chunk完整文本消息；若本轮已经发送过 delta，会避免重复发送完整消息。
tools.availableagent_thought_chunk本轮暴露给模型的工具列表。
tool.startedtool_callagent loop 工具开始执行，包含 toolCallId、title、status。
tool.completed / tool.failedtool_call_updateagent loop 工具完成或失败，结构化结果在 rawOutput。
skill.startedtool_callworkflow 或 skill-backed tool 开始执行。
skill.completedtool_call_updateworkflow 或 skill-backed tool 完成，结构化结果在 rawOutput。
artifact.createdagent_thought_chunk产物生成或更新；产物详情在 _meta.jetlinksRuntimeEvent.data.artifact。
verifier.startedtool_call内容校验开始。
verifier.completedtool_call_update内容校验完成，结果在 rawOutput。
run.completedagent_thought_chunk本轮完成，最终结果也会通过同 id 的 RPC result 返回。
run.failedagent_thought_chunk执行失败；错误或结果仍在 _meta.jetlinksRuntimeEvent。

运行观测与 Debug Bundle

每次运行都会生成 run_id，事件会持久化到 .runtime/runs/{run_id}.json。实时事件通过 ACP session/update 回传；历史详情可通过 HTTP 查询。

实时观测

工具失败诊断

工具失败事件会带结构化 error_code，便于 Java 或前端直接分类处理。

TOOL_DISABLED工具已注册但被禁用，例如本地 shell 工具未开启。

本地部署与 Java 进程管理

仓库根目录提供了一组脚本，适合本机部署、Java ProcessBuilder 或其他进程管理器调用。

脚本用途说明
./install-deps.sh安装 Python 依赖。创建 .venv 并安装 requirements.txt。
./up.sh后台启动服务。启动前检查 Python 依赖，启动后轮询 /health。
./status.sh查看状态。输出机器可读的 status=running pid=... health=ok。
./stop.sh停止服务。先发送 SIGTERM，超时后 SIGKILL。
./restart.sh重启服务。等价于 stop 后 up。
 
./install-deps.sh
APP_HOST=0.0.0.0 APP_PORT=8000 ./up.sh
APP_PORT=8000 ./status.sh
APP_PORT=8000 ./restart.sh
APP_PORT=8000 ./stop.sh

状态输出与退出码

status=running pid=12345 health=ok url=http://127.0.0.1:8000 log=.runtime/server/server.log
退出码含义
0运行中且健康检查正常。
2进程存在但健康检查失败。
3未运行或 PID 文件过期。
10up.sh 检测到 Python 依赖缺失，需要先执行 ./install-deps.sh。

Java ProcessBuilder 示例

ProcessBuilder builder = new ProcessBuilder("./status.sh");
builder.directory(new File("/opt/jetlinks-agent-runtime"));
builder.redirectErrorStream(true);
builder.environment().put("APP_PORT", "8000");

Process process = builder.start();
String output = new String(process.getInputStream().readAllBytes(), StandardCharsets.UTF_8);
int exitCode = process.waitFor();

// output example:
// status=running pid=12345 health=ok url=http://127.0.0.1:8000 log=.runtime/server/server.log
